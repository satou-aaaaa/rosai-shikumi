# 労災のしくみ（rosai-shikumi）

仕事中・通勤中のけがは労災になる？休んだら何日目から、いくら出る？場面を見て、労働者災害補償保険法（労災保険法）と労働基準法の決まりどおりの答えを選ぶ1日5問の学習ゲーム。正解したら「これは、どの決まり？」も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/rosai-shikumi/>

- 答えは、e-Gov 法令検索の労災保険法（<https://laws.e-gov.go.jp/law/322AC0000000050>）・同法施行規則（<https://laws.e-gov.go.jp/law/330M50002000022>）・労働者災害補償保険特別支給金支給規則（<https://laws.e-gov.go.jp/law/349M50002000030>）・労働基準法（<https://laws.e-gov.go.jp/law/322AC0000000049>）の条文で確かめたことだけです（2026年11月17日に読みました）。
- 人の名前・給料は作り話です。毎年変わる金額（給付基礎日額の最低保障額・年齢ごとの上限など）は答えにしません。労災かどうかは、ひとつひとつ労働基準監督署が調べて決めます。
